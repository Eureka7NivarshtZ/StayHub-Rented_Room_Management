# StayHub – Rental Property Management Website

## 1. Project Introduction

StayHub is a rental property management website designed to help landlords manage rental properties, rooms, tenant information, rental agreements, and income and expenses.

The system follows a model in which one landlord can manage multiple rental properties and multiple rooms on a single platform.

## 2. Project Objectives
- Digitize the rental property management process.
- Minimize errors caused by managing information through paper documents or spreadsheets.
- Support tracking room availability and tenant information.
- Manage rental fees, electricity, water bills, and payment statuses.
- Implement role-based access control for different types of users.

## 3. System Actors
| Actor | Role |
|---|---|
| Landlord | Manages rental properties, rooms, tenants, rental agreements, and invoices. |
| Tenant | Views room information, rental agreements, and payment statuses. |
| Administrator | Manages user accounts and system permissions. |

## 4. Planned Features
### Landlord
- Manage multiple rental properties.
- Manage room listings.
- Manage tenant information.
- Manage rental agreements.
- Manage invoices for rent, electricity, and water.
- Track payment statuses.

### Tenant
- View current rental room information.
- View rental agreement details.
- View invoices.
- Check payment statuses.

### Administrator
- Manage user accounts.
- Assign and manage user permissions.
- Monitor and manage the system.

## 5. Planned Technologies
- **Frontend:** HTML, CSS, JavaScript, ReactJS.
- **Backend:** Node.js, Express.js.
- **Database:** MySQL.
- **Version Control:** Git and GitHub.
- **Deployment:** Vercel.
